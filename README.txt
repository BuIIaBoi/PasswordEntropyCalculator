 How to run the program
	To run the program,
	1. Make sure you have python downloaded
	2. Open a terminal the file
	3. Write "python Project_v3.py"
	4. Enter your password
 What the user should expect
	1. User will get a prompt asking of a password
	2. Program will calculate entropy and return entropy score
	3. If entropy is below 30, Program gives feedback on how to increase password strength
